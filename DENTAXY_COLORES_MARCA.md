# Dentaxy — Colores y Guía de Marca

Este documento contiene los colores oficiales y variables de diseño de Dentaxy, con base en nuestros tokens de diseño (*Futuristic, Clean, Apple-like*).

## Paleta de Colores

### Colores Principales (Primary)
Estos colores se utilizan para acciones clave, botones principales y elementos destacados.
- **Color Base (`primary.DEFAULT`):** `#2563EB` (Azul)
- **Color Hover (`primary.hover`):** `#1D4ED8` (Azul oscuro para interacciones)
- **Texto sobre Primary (`primary.foreground`):** `#FFFFFF` (Blanco)

### Colores Secundarios (Secondary)
Estos tonos son para elementos secundarios, insignias y toques visuales vibrantes.
- **Color Base (`secondary.DEFAULT`):** `#4ADE80` (Verde)
- **Texto sobre Secondary (`secondary.foreground`):** `#FFFFFF` (Blanco)

### Interfaz y Fondos
- **Fondo General (`background`):** `#FFFFFF` (Blanco puro para un estilo limpio)
- **Texto Principal (`foreground`):** `#09090B` (Gris casi negro para alta legibilidad)
- **Color Apagado / Contenedores (`muted` y `accent`):** `#F4F4F5` (Gris claro)

### Estados y Semántica
- **Destructivo/Error (`destructive`):** `#EF4444` (Rojo)
- **Éxito / Confirmación (`success`):** `#10B981` (Verde esmeralda)

## Tipografía Oficial
Las fuentes principales para la identidad de la marca son:
1. **M PLUS 1p**
2. **Inter**
*Alternativa del sistema: sans-serif*

**Pesos:**
- Normal: `400`
- Medio: `500`
- Negrita/Bold: `700`

## Efectos Exclusivos UI
- **Efecto de Glassmorfismo (Glassmorphism Dentaxy):** `bg-secondary/30 backdrop-blur-sm`
- **Bordes (Rounded):** Predominantemente redondeados (0.75rem / 12px por defecto, hasta 16px para contenedores grandes).
