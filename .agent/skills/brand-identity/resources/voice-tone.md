# Copywriting: Voz y Tono

Al generar texto para Dentaxy, adhiérase estrictamente a esta personalidad de marca.

## Personalidad de la Marca
* **Profesional pero Cercano:** Somos expertos médicos, pero hablamos claro.
* **Futurista y Eficiente:** Valoramos la tecnología y la velocidad. "Menos es más".
* **Empático:** Entendemos al dentista y al paciente.
* **Idioma:** Español (México) por defecto.

## Reglas de Gramática y Mecánica
* **Encabezados:** Capitalización tipo Título (H1), tipo oración para subtítulos.
* **Puntuación:** Evite signos de exclamación (!) excesivos. Use puntos para oraciones completas.
* **Claridad:** Prefiera voz activa. Mantenga las oraciones concisas.
* **Terminología Médica:** Use términos correctos (ej. "Odontograma", no "Mapa de dientes"), pero explique si es necesario para estudiantes.

## Guía de Terminología

| No Usar | Usar en su lugar |
| :--- | :--- |
| "Utilizar" | "Usar" |
| "Checar" | "Revisar" |
| "Loguearse" | "Iniciar Sesión" |
| "Error Fatal" | "Ocurrió un problema" |
| "IA Generativa" (al usuario) | "Asistente de Redacción" o "Autocompletado" |

## Mensajes Clave
* "Revolucionando la odontología en México."
* "Adiós al papel. Hola Dentaxy."
* "Tecnología propietaria de alta eficiencia."
